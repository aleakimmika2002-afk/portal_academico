# Portal Académico

Sistema web desarrollado con Python y Flask para el segundo parcial práctico de Tecnologías Emergentes II.

## Descripción

El sistema permite:

- Iniciar sesión con usuarios registrados.
- Mantener la sesión mediante Flask.
- Proteger las rutas de cursos y perfil.
- Mostrar cursos utilizando plantillas Jinja2.
- Mostrar la disponibilidad de cupos.
- Guardar el usuario preferido mediante cookies.
- Eliminar la cookie del usuario.
- Cerrar la sesión.
